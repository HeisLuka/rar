# Chaptera Desktop

Current Rar-owned desktop product target for Desktop Portable V0.

This application is derived from the historical `HeisLuka/yab/apps/pub-viewer` shell, but its source and build authority live in `HeisLuka/rar`. The donor repository is provenance only.

V0 scope:
- open supported real PUB through the admitted reverse/viewer stack;
- capability-gated ordinary Story editing;
- Undo/Redo and EditorProject sidecar persistence;
- bounded editable IDML/ODG export;
- direct page-local MoveNode only after current scene-instance mutation admission.

Not in V0: native Save PUB, master/Cmo object authoring, Resize, ReplaceImage, snapping, rotate/z-order, full Publisher parity.
